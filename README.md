# Week 1 – Practical Exercise (Registration UI)

## Overview
A front-end registration interface (HTML/CSS/JS) focusing on JavaScript events and event-handling:
- Real-time validation + error feedback
- Password strength meter + show/hide password
- Email domain autocomplete suggestions
- Phone auto-formatting
- “Terms accepted” 
- LocalStorage draft saving (no backend)

## How to run
Just open `index.html` in a browser.

## Notes
No backend implemented. This project demonstrates client-side interactivity and validation.
